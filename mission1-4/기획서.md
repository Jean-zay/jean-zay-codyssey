
# 내 영화 티어리스트 기획서 

## 누가 쓰나
- 나와 영화를 좋아하는 친구들

## 무엇을 하려고
- 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리합니다.
- **각 등급에 영화가 몇 편씩 쌓였는지 한눈에 확인합니다.**

## 화면과 동작
- 위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다.
- **각 등급 라벨과 '아직 안 정한 영화' 제목 옆에 현재 영화 개수가 표시됩니다.**
- 카드를 누르고 등급 글자를 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다.
- 제목을 입력하고 ‘추가’를 누르면 아직 안 정한 영화에 카드가 생기며, **개수가 즉시 업데이트됩니다.**
- 영화 목록과 등급 배치를 브라우저에 자동으로 저장합니다.
- ‘처음으로’를 누르면 처음 영화 목록과 배치로 돌아가며 **개수도 초기화됩니다.**

## 필요한 자료
- 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리

## 완성 기준
1. **영화가 한 칸에만 있고, 옮긴 칸에 남습니다.**
2. **제목을 입력하면 새 영화 카드가 생깁니다.**
3. **같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.**
4. **화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.**
5. **‘처음으로’를 누르면 처음 영화 8개가 모두 미분류로 돌아갑니다.**
6. **외부 파일·로그인·서버 실행 없이 HTML 한 장으로 열립니다.**
7. **빈 제목은 추가하지 않습니다.**
8. **[신규] 각 등급별(S, A, B, C) 및 미분류 칸에 포함된 영화의 개수가 화면에 실시간으로 표시됩니다.**
