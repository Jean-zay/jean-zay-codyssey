# 미션3_기록

실제로 내가 발견한 지점도 있었고, AI가 작성한 부분은 미처 내가 발견하지 못한 부분까지 발견했었다. 동료 피드백은 취향의 관점에서 접근한 지점이었다.

생각해 보면 두 관점 모두 필요하다고 생각한다. 결국 사람이 사용하기에 취향적인 관점도 필요하고, 기술적인 부분도 사용에는 꼭 필요한 지점이기 때문이다.

## AI의 답, 동료 피드백, 직접 확인한 내용

| 분류 | 의견 | 고르기 | 이유 |
|---|---|---|---|
| 나 | ‘선택한 영화 되돌리기’를 눌러도 작동하지 않음 | 반영 | 직접 해 보니 작동하지 않았고, 있는 버튼이 동작하지 않는 오류임 |
| 나 + AI | 같은 브라우저에서 파일을 다시 열면 영화와 등급이 남지 않음 | 반영 | 직접 해 보니 그랬고, 완성 기준인 ‘다시 열어도 영화와 등급이 남는다’를 어김 |
| AI | ‘처음으로’를 눌러도 직접 추가한 영화가 남음 | 반영 | 기획서의 ‘처음 영화 목록과 배치로 돌아간다’는 약속과 다름 |
| AI | 제목을 비워도 ‘추가’가 되어 빈 카드가 생김 | 반영 | 글자 없는 카드는 목록의 목적에 맞지 않음 |
| 나 + 동료 | C칸은 없어도 됨 | 반영 | 아쉬운 영화를 따로 둘 이유가 없다는 데 둘 다 동의함 |
| 나 | 포스터형 카드 대신 영화 제목만 보이는 카드면 충분함 | 반영 | 제목만으로 분류에 충분하고, 화면이 단순해짐 |
| 동료 | 포스터 사진이 같이 나오면 좋겠음 | 보류 | 제목만 보이는 카드로 정했으므로 방향이 반대이고, 취향의 문제임 |
| 동료 | 휴대폰에서 열면 불편함 | 보류 | 적용하지 않기로 함. 어떤 점이 불편한지도 구체적이지 않음 |
| 동료 | 카드 옮기는 게 처음엔 헷갈림 | 보류 | 적용하지 않기로 함. 무엇이 헷갈렸는지 구체적이지 않음 |
| 동료 | 미분류 목록이 맨 아래라 S칸까지 끌기 불편함 | 보류 | 적용하지 않기로 함. 화면 배치를 크게 바꿔야 하는 일임 |
| 동료 | 카드 색이 칙칙함 | 보류 | 취향이라 꼭 바꿀 이유가 없음 |
| 동료 | 등급별 색, ‘8편 중 3편 나눔’, 끌 때 칸 색 변화가 좋았음 | 유지 | 칭찬이므로 수정할 때 이 부분이 깨지지 않게 그대로 둠 |

> ‘처음으로’와 빈 제목 항목은 직접 확인한 목록에 없던 내용이다. 고치기 전에 직접 해 보고, 실제로 그렇지 않다면 ‘보류’로 바꾼다.
