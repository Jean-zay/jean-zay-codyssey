
영화 티어리스트 기획서

지금까지 나눈 대화를 바탕으로 정리한 기획서입니다.

1. 누가 쓰나
주 사용자: 나 혼자 쓰는 개인용
로그인: 회원 기능은 없음. 단, 나만 수정할 수 있을 정도의 간단한 방식은 필요
친구: 가끔 링크로 보여주기만 함 → 보기 전용(수정 불가), 링크를 아는 사람만 접근
보기 전용 화면에서 포스터를 누르면 한줄평은 보임 / 본 날짜는 안 보여도 됨
2. 무엇을 하려고
내가 본 영화를 S~F 등급으로 정리·기록하는 것
시간이 지나도 "이 영화 몇 등급 줬더라?"를 바로 확인
새 영화를 보면 계속 추가
공유는 부가 기능. 여러 사람 투표 기능은 필요 없음
3. 화면과 동작
핵심 동작
영화 포스터를 끌어다(드래그 앤 드롭) 등급 칸에 놓기
이미 놓은 영화를 다른 칸으로 이동, 같은 칸 안에서 순서 변경
등급 칸 ↔ 미분류 보관함 양방향 이동
화면 구성
검색창: 화면 위쪽, 눈에 띄지만 크지 않게 하나. 결과는 포스터 썸네일 + 제목·연도로 간단히
등급 칸: 좌측에 등급 글자가 든 색 블록 + 우측에 포스터 가로 나열(전형적 티어리스트 형태). 칸 간격 넉넉, 모서리 살짝 둥글게
미분류 보관함: 화면 아래쪽, 등급 칸과 구분되는 차분한 영역. 비었을 때 "영화를 검색해서 추가해 보세요" 같은 안내 문구
팝업: 포스터 클릭 시 가운데 작은 카드. 포스터·제목·본 날짜·한줄평만
디자인
전체: 미니멀, 파스텔톤. 포스터가 주인공이 되는 깔끔한 화면
배경: 따뜻한 아이보리 또는 연한 회색 (눈부시지 않게)
등급 색상(파스텔, 낮은 채도): S 연분홍 / A 살구 / B 연노랑 / C 연두 / D 하늘 / F 연보라
포스터: 같은 크기·비율로 정렬, 둥근 모서리, 아주 옅은 그림자, 드래그 시 살짝 떠오르는 느낌
글꼴: 깔끔한 산세리프(Pretendard 같은 느낌), 너무 진하지 않은 짙은 회색 글자
모바일: 포스터 작아지고 등급 칸이 화면 폭에 맞게 줄바꿈, 가로 스크롤 없이
다크 모드: 필수 아님. 지원 시 파스텔 색이 탁하지 않게
4. 필요한 자료
영화 추가 방식
기본: 영화 검색 시 포스터·정보 자동 불러오기 (외부 영화 데이터 서비스 연동 필요)
보조: 검색에 안 나오는 영화는 제목 직접 입력 + 포스터 직접 업로드
※ 이 수동 입력은 나중으로 미루는 항목(아래 완성 기준 참고)
영화 한 편당 저장 정보
제목 (기본)
포스터 (기본)
본 날짜
한줄평
개봉 연도·감독: 검색 시 자동으로 따라오면 좋음 (직접 입력할 필요는 없음)
별점: 저장하지 않음 (등급 S~F이 평점 역할)
등급
S / A / B / C / D / F 고정
데이터 보관
서버/클라우드에 저장 (어느 기기에서든 보이고, 브라우저 데이터를 지워도 유지)
비용은 무료이거나 아주 적게. 데이터 양은 많지 않음
5. 완성 기준
1차 완성(꼭 있어야 할 것)
영화 검색 → 미분류 보관함에 추가
드래그로 등급 칸 배치, 칸끼리·보관함으로 자유롭게 이동
포스터 클릭 시 본 날짜·한줄평 입력/확인 팝업
다음에 열어도(다른 기기에서도) 그대로 남아 있음
휴대폰에서도 드래그가 잘 됨
나중으로 미뤄도 될 것(2차)
수동 입력(포스터 직접 업로드)
친구용 보기 전용 링크
등급 칸 이름 바꾸기 (예: "인생영화", "다시 안 봄")
