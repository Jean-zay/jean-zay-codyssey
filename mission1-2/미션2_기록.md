## 수정 1-① 끌어 놓은 카드가 무작위로 등급 칸에 옮겨지지 않음

### 좁히려고 해 본 것과 결과

| 해 본 것 | 결과 |
| --- | --- |
| 미분류의 카드를 끌어 S·A·B·C 칸에 여러 번 놓아 봄 | 처음에는 B·C 칸, 다시 했을 때는 S 칸에 놓을 수 없었음 |
| 안 되는 카드가 정해져 있는지 확인 | 같은 카드도 될 때와 안 될 때가 있었음. 특정 카드나 등급의 문제가 아님 |
| **결론** | 카드나 등급이 아니라 **카드를 놓은 자리**에 따라 결과가 달라지는 것으로 좁힘 |

### AI가 말한 원인과, 그 설명을 직접 확인한 결과

| 항목 | 내용 |
| --- | --- |
| AI가 말한 원인 | 끌어 놓기 기능(`dragover`, `drop`)이 각 줄의 오른쪽 칸(`.drop`)에만 연결되어 있다. 등급 글자 버튼(`.label`)과 줄 전체(`.row`)에는 연결되어 있지 않아, 등급 글자 위에 놓으면 받아 주지 않는다. |
| 코드 확인 | `wireDrop(drop, tier)`가 `.drop`에만 호출되는 것을 확인 |
| 직접 확인 | 같은 카드를 등급 글자 위와 오른쪽 빈 곳에 각각 놓아 본 결과, 오류없이 구동이 됌

## 수정 1-② 새로 추가한 영화 카드가 등급 칸으로 옮겨지지 않음

### 좁히려고 해 본 것과 결과

| 해 본 것 | 결과 |
| --- | --- |
| 제목을 입력하고 '추가'를 눌러 카드 생성 | 카드는 미분류에 정상으로 생김 |
| 그 카드를 끌거나, 누른 뒤 등급 글자를 눌러 옮겨 봄 | 어느 칸으로도 옮겨지지 않음 |
| 여러 번 다시 시도 | 매번 실패함 |
| **결론** | 무작위로 실패하는 수정 1-①과 달리 매번 실패하므로 원인이 다르다고 판단 |

### AI가 말한 원인과, 그 설명을 직접 확인한 결과

| 항목 | 내용 |
| --- | --- |
| AI가 말한 원인 | 카드를 만들 때 `data-id=` 값에 따옴표가 없어 `해리 포터` 같은 제목이 `해리`까지만 읽힌다. 저장된 영화를 찾지 못해 끌기와 누르기가 모두 무시된다. |
| 코드 확인 | `'data-id=' + item.id + '>'`처럼 따옴표 없이 값을 넣는 것을 확인 |
| 직접 확인 | 띄어쓰기가 있는 제목과 없는 제목(예: 듄)을 각각 추가해 옮겨 본 결과, 오류없이 구동이 됌

## 수정 2. 부제목의 마지막 '됩니다.'만 다음 줄로 내려감

### 좁히려고 해 본 것과 결과

| 해 본 것 | 결과 |
| --- | --- |
| 부제목이 어디서 줄이 바뀌는지 확인 | 문장 끝의 '됩니다.'만 다음 줄로 떨어짐 |
| 전체 문장이 한 덩어리로 이어지도록 수정 요청 | (수정 후 결과 입력) |

### AI가 말한 원인과, 그 설명을 직접 확인한 결과

| 항목 | 내용 |
| --- | --- |
| AI가 말한 원인 | 부제목(`.sub`)에 `max-width:46ch`가 걸려 있다. `ch`는 숫자 0의 너비 기준이라 한글보다 좁아서, 46ch 안에 문장이 다 들어가지 못하고 끝부분이 다음 줄로 넘어간다. |
| 코드 확인 | `.sub { ... max-width:46ch; }`를 확인 |
| 직접 확인 (넓은 화면) | 제한을 없애거나 늘린 뒤 한 줄로 보이는지 확인후 , 오류없이 구동이 됌
