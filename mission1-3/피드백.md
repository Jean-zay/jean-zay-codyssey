# 민수_영화티어리스트 피드백

## 잘된 점

- 등급마다 색이 달라 어느 칸이 S인지 한눈에 들어왔다.
- 위에 ‘8편 중 3편 나눔’이 나와 얼마나 남았는지 알 수 있었다.
- 카드를 끌어다 놓을 때 칸 색이 살짝 바뀌어 어디에 놓이는지 알 수 있었다.

## 고치면 좋을 점

### 1. ‘선택한 영화 되돌리기’가 작동하지 않음

- **본 것:** 영화를 선택하고 ‘선택한 영화 되돌리기’를 눌렀더니 아무 일도 일어나지 않았다.
- **기준:** 기획서에 있는 ‘선택한 영화 되돌리기’ 기능
- **제안:** 누르면 선택한 영화가 미분류로 돌아가면 좋겠다.

### 2. 다시 열면 배치가 남지 않음

- **본 것:** 영화를 등급에 나눈 뒤 같은 브라우저에서 파일을 다시 열었더니 모든 영화가 미분류로 돌아가 있었다.
- **기준:** 기획서의 ‘같은 파일을 다시 열어도 영화와 등급이 남습니다’
- **제안:** 브라우저에 배치를 저장해서 다시 열어도 영화와 등급이 그대로 남으면 좋겠다.

### 3. ‘처음으로’가 직접 추가한 영화를 지우지 않음

- **본 것:** 영화를 직접 추가하고 ‘처음으로’를 눌렀더니 처음 영화 8개는 미분류로 돌아갔지만 추가한 영화는 그대로 남았다.
- **기준:** 기획서의 ‘처음 영화 목록과 배치로 돌아갑니다’
- **제안:** ‘처음으로’를 누르면 직접 추가한 영화도 지워지고 처음 영화 8개만 미분류로 남으면 좋겠다.

### 4. 빈 제목으로도 카드가 추가됨

- **본 것:** 제목을 비워 둔 채 ‘추가’를 눌렀더니 글자 없는 카드가 생겼다.
- **기준:** (기획서에 없음) 빈 카드는 어떤 영화인지 알 수 없어 분류할 수 없었다.
- **제안:** 제목이 비어 있으면 카드가 추가되지 않고 제목을 입력하라는 안내가 나오면 좋겠다.

### 5. C칸이 필요 없음

- **본 것:** 등급을 나누다 보니 C칸에는 넣을 영화가 없었다.
- **기준:** (기획서에 없음) 아쉬운 영화를 따로 둘 이유가 없어 칸만 하나 더 늘어난 느낌이었다.
- **제안:** C칸을 없애면 좋겠다.

### 6. 포스터형 카드가 필요 없음

- **본 것:** 영화 카드가 포스터를 보여 주는 형태로 나왔다.
- **기준:** (기획서에 없음) 분류할 때는 제목만으로 충분해서 포스터 자리가 화면만 복잡하게 했다.
- **제안:** 영화 제목만 보이는 카드로 바뀌면 좋겠다.
