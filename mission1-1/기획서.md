# 영화 티어리스트 기획서

## 1. 누가 쓰나
- **사용자**: 본인 한 명 (개인용)
- **로그인**: 불필요
- 본 영화를 등급별로 기록·관리하려는 개인 사용자

## 2. 무엇을 하려고
- 본 영화를 **S~F 등급**으로 분류해 기록·관리
- 드래그 앤 드롭으로 **직관적으로** 등급을 지정
- PC와 모바일 양쪽에서 사용

## 3. 화면과 동작
**화면 구성**
- 상단: 제목 입력창 + 추가 버튼
- 그 아래: 전체 초기화 버튼
- 중단: 등급 행 6개 (S / A / B / C / D / F), 파스텔 색상 구분
- 하단: 미분류 보관함

**동작**
- 영화 **추가**: 제목 입력 → 미분류에 카드 생성
- **중복 제목 차단**: 이미 있는 제목은 추가 안 됨 (안내)
- **드래그 앤 드롭**: 등급 간 이동 담당
  - PC: 마우스 드래그
  - 모바일: 터치 드래그 지원
- **등급 내 자동 정렬**: 같은 등급 안에서는 항상 **가나다순** 정렬 (수동 순서 변경 없음)
- **삭제**: 카드의 × 버튼
- **전체 초기화**: 모든 데이터 삭제 후 예시 10편으로 되돌림 (확인창)
- **저장**: localStorage 자동 저장 (새로고침해도 유지)

## 4. 필요한 자료
- **저장 데이터**: 영화 제목 (id, 제목, 소속 등급)
- **예시 영화 10편** (최초 실행 시 미분류에 자동 포함):
  기생충 / 인터스텔라 / 이터널 선샤인 / 라라랜드 / 헤어질 결심 / 인사이드 아웃 2 / 탑건: 매버릭 / 트랜스포머: 사라진 시대 / 존 오브 인터레스트 / 퍼펙트 데이즈

## 5. 완성 기준
- 단일 HTML 파일로 동작
- 예시 10편이 미분류에 표시됨
- 제목 입력으로 새 영화 추가 가능 (중복 제목은 차단)
- PC 마우스 드래그로 등급 간 이동 가능
- 모바일 터치 드래그로 등급 간 이동 가능
- 같은 등급 안에서 가나다순 자동 정렬
- 카드 삭제 가능
- 전체 초기화 버튼으로 예시 상태로 복원 가능
- 새로고침 후에도 데이터 유지 (localStorage)
- PC·모바일 반응형 레이아웃

- 전체 초기화 버튼 → **추가하기로 확정**
- 중복 제목 처리 → **차단하기로 확정**
- 등급 내 정렬 → **가나다순 자동 정렬로 확정** (수동 순서 변경은 폐기)
