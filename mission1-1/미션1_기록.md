## AI가 물어서 내가 정한 것

AI A가 던진 질문에 답하면서 사용자 목적, 핵심 동작, 데이터 출처, 화면 구성, 결과 저장·공유 방식, 사용 기술을 직접 정했습니다. 이렇게 정리된 기획 내용을 두 AI에 동일하게 전달해 비교 기준으로 삼았습니다.

## 같은 행동으로 비교한 결과

- 해본 행동: AI가 먼저 질문하도록 유도하는 동일한 요청과 기획 내용을 두 모델에 전달하고, 결과물을 실행해 봄
- 기대 결과: 영화 목록이 표시되고, 사용자가 여러 옵션 중에서 선택할 수 있는 화면
- A의 결과: 결과물이 정상적으로 구동되지 않았고, 장르 미분류 영화들의 목록이 표시되지 않았음. 색상 구성도 정돈되지 않아 화면이 조잡해 보였음
- B의 결과: 기획대로 영화 목록이 표시되고 선택 기능이 정상 동작함

## 선택한 파일명과 고른 이유

`제미나이 3 플래시.md`를 선택했습니다. 같은 조건에서 기획서의 핵심 동작(영화 목록 표시 → 선택)이 빠짐없이 구현되었고 실제로 구동되었기 때문입니다. A는 실행 자체가 되지 않고 미분류 영화 목록이 누락되어, 핵심 기능을 확인할 수 없었습니다.

## 배운 점 (동료에게 공유하고 싶은 것)

같은 기획과 요청을 넣어도 모델마다 결과물의 완성도가 달랐습니다. 처음에는 화면만 보고 판단하려 했지만, 직접 실행해 보니 구동 여부와 데이터 누락(미분류 영화) 같은 차이가 드러났습니다. 결과물은 반드시 실행해서 "기대 결과"와 대조해 보는 것이 중요하다는 점을 배웠습니다. 또 기능 구현을 먼저 확인한 뒤 디자인과 공유 기능을 다듬는 순서로 진행하니 수정 범위를 명확히 정할 수 있었습니다.
